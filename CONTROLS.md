# LEONIDA — Controls

Click the game canvas once to lock the mouse. Press `Esc` to release it / open the pause menu.

## On foot

| Key | Action |
|---|---|
| `W A S D` | Move |
| Mouse | Look / orbit camera |
| `Shift` | Sprint |
| `Alt` | Walk |
| `Space` | Jump |
| Right mouse | Aim (over-the-shoulder) |
| Left mouse | Fire / punch |
| `R` | Reload |
| `Tab` (hold) | Weapon wheel (slow-mo) |
| `1`–`6` | Quick-select weapon |
| Mouse wheel | Cycle weapons |
| `F` | Enter nearest vehicle / carjack |
| `E` | Interact (doors, shops, casino tables, rob) |
| `Q` | Character wheel (switch Lucia / Jason) |
| `Caps Lock` | Adrenaline ability (slow-mo) |
| `M` | Full map (click to set a waypoint) |
| `Up arrow` | Phone |
| `Esc` | Pause menu |
| `F3` | Performance overlay |

## In a vehicle

| Key | Action |
|---|---|
| `W` / `S` | Throttle / brake & reverse |
| `A` / `D` | Steer |
| `Space` | Handbrake |
| `F` | Exit vehicle |
| `H` | Horn |
| `L` | Headlights |
| Left mouse | Fire out of the window (pistol / SMG) |
| Mouse | Look around (auto-centers when idle) |

## Robbing

- Aim a gun at a pedestrian for 1.5 s: they drop cash.
- Aim a gun at a store clerk (24/7, gas station, Waffle Hut): they fill a bag. Firing a shot speeds it up but makes noise. Grab the cash and leave — expect two stars.
- Drive a stolen car into the chop shop marker at the Docks to sell it.
- Drive into Vice Sprays with a wanted level to lose the cops ($1,000 per star).
